Roosevelt Networks

Developed by Anna Cao. Dataset built and populated by Anna Cao, Victoria Li, and Audrey Lau.

ARCH 5115 / Designing the Urban Commons / Garine Boghossian and Kobi Ruthenberg

Cornell University, Fall 2026

Roosevelt Networks is an interactive model of the actors that shape Roosevelt Island (agencies, organizations, institutions, buildings and people) and the relationships between them. This documentation explains how to use the app, how the model is constructed, and how to load your own dataset.

Roosevelt Networks reads its data from a Google Spreadsheet published to the web, so any network with the same structure can be loaded. The app's source code is on GitHub.

1. Prepare the spreadsheet

Make a copy of the project dataset and replace its contents with your own, keeping the column headers. Two tabs are required:

Actors (actor_working), one row per actor:

ColumnContents
actorFull name. Must be unique, and must match the names used in the adjacency tab.
abbrevShort name (optional), also searchable.
topicCategory or categories, comma-separated.
typeSector.
scaleScale, for example 0 - MICRO, 1 - MESO, 2 - MACRO.
year_start, year_endActive years (optional).
public sentimentSentiment rating (optional).

Relationships (adjacency), one row per connection:

ColumnContents
source-target relationshipOne of the relationship types, for example COLLABORATION or OWNER-TENANT.
source, targetActor names, exactly as written in the actors tab.
parameter 0–parameter 2 Optional details: parcel area in sq ft (Owner–Tenant, parameter 0); one-time and a whole-number closeness (Collaboration, parameters 0 and 1); upfront investment and yearly funds in dollars (Financial, parameters 0 and 1); elected, succession or appointment (Position–Incumbent, parameter 0).

Blank cells are fine. Rows whose actors can't be found are skipped and reported in the browser console.

2. Publish it

In Google Sheets, choose File → Share → Publish to web and publish the entire document. Note the published URL and the gid of each tab (the number after gid= in the tab's address).

3. Point the app at it

  1. Fork or download the repository.
  2. In src/config.js, replace publishedUrl, actorGid and adjacencyGid with your own values.
  3. Run npm install, then npm run dev, and click Relink data to load your sheet.
  4. Optionally, save CSV snapshots of your tabs over public/data/actors.csv and public/data/edges/adjacency.csv so the app opens with your data before relinking.

To add a new relationship type, add its label to public/data/edges/manifest.json and map the spreadsheet's name for it in SHEET_ADJACENCY_TYPES in src/config.js. Map-mode building data is described in the repository's README.
